Week 2: investigator loop and RiskReport

Status: active Owner: Oded Goldberg Last updated: 2026-10-16 Branch: feat/week2-investigator

Week 1 shipped the synthetic org, read-only tools and a naive baseline that breaks 6 of 10 risky cases. Week 2 adds the agent: two swappable interfaces, a tool-calling loop, and a structured report where every finding cites evidence ids that code verifies.

GoalScopeAssumptionsOpen QuestionsStepsValidationRisksRollout OrderRollback

Goal

investigate(request) -> RiskReport runs a tool-calling loop over an LLMClient and returns safe_to_delete, disable_first or ask_owner with a confidence. Every finding cites evidence ids that exist in that run's tool log. Proven end-to-end with FakeLLM, plus one smoke run on Bedrock.

Evidence ids are assigned by code, never by the model. A report can only cite what a tool actually returned in this run.
